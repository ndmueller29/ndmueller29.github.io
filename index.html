Portfolio Optimization Engine

code ↗ demo ↗
— started as a class project, kept going
Problem

Retail investors don't have easy access to constrained mean-variance optimization with realistic transaction costs.

Approach

Convex optimization over a rolling asset universe, backtested against historical price data with turnover penalties.

Options Pricing & Greeks Simulator

code ↗
— Black-Scholes, then I got curious about the Monte Carlo error
Problem

Compare closed-form Black-Scholes pricing against Monte Carlo simulation and quantify convergence.

Approach

Vectorized Monte Carlo with variance reduction (antithetic variates), Greeks via finite differences.

Result

Cut simulation runtime substantially versus a naive loop implementation while holding pricing error within a tight tolerance.
